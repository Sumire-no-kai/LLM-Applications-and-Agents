# Repository guidance

- This repository is a personal technical notebook for learning to build LLM applications and agents, in two topics: the agent harness and retrieval-augmented generation (RAG). Write study notes primarily in Chinese and preserve the author's voice. The README may be bilingual.
- Put each note in its topic directory (`Harness/`, `RAG/`). A note may start from one question or explore one concept; do not impose a fixed template.
- Each topic's README is its study roadmap. When a note covers a knowledge point there, link the note from the README's Notes list and keep the roadmap accurate.
- Distinguish verified results (code that ran, measurements, documentation checked on a stated date) from hypotheses or open questions. Do not invent outcomes, numbers or product behaviour.
- Products, specifications and defaults change quickly. Cite a primary source for claims about them, and say when it was checked.
- Follow the existing organization and formatting when editing notes, and check any new or changed relative links.
- Keep public-facing descriptions focused on the study notes and what readers will find here.
